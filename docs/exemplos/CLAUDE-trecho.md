## Conferir telas com a Ferramenta de Captura (MCP "captura-tela")
- Para ver como o app/pagina ficou, use as ferramentas do MCP `captura-tela`: `list_windows`, `capture`, `ocr`, `record_gif`.
- Prefira capturar **uma janela** (`window`) a tela inteira; so use `fullscreen` se eu pedir.
- Use `max_width` 1280 e, em janelas lentas, `delay_ms` de 500 a 1000.
- Antes de me mostrar ou guardar uma imagem com dados pessoais, esconda-os com `annotate` (`blur`/`pixelate`).
- O MCP so le a tela: nao clica nem digita. Se eu negar uma permissao, nao tente contornar; me diga o que precisa.
